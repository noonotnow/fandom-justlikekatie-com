---
name: MemeForge reaction-card format
description: The three intentional source paths and why clean-still reaction cards are a finished product format.
---

MemeForge should preserve three distinct creation paths: keep an existing meme unchanged, rework an existing meme, or make a reaction card from a clean still. The canonical reaction-card example is the clean Gandalf still with the original “Netflix: approaches” joke in MemeForge’s editorial system, contrasted with the unchanged inherited meme. The reaction-card path is a finished, sendable output—not a temporary step before image editing arrives.

**Why:** An original joke on a clean still travels better than a crusty inherited JPEG while keeping reaction utility.

**How to apply:** The reaction-card path now renders with the shared C-drama meme renderer (`renderMemeCanvas`: full-bleed still, outlined top/bottom type, TikTok 9:16 or Instagram 4:5). The earlier parchment/editorial card frame was retired at the creator's request. Keep source provenance and joke hierarchy intentional. Future Adobe-style editing should expand the “rework meme” path without replacing reaction cards. Use the user-facing choice “Keep original · Rework meme · Make reaction card” when the workshop exposes all three paths.
