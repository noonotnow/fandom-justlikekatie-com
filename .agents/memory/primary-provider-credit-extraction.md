---
name: Primary provider credit extraction
description: Browser markdown can omit iQIYI's real actor-to-character credits; source HTML is a useful primary evidence alternative.
---

Do not infer role mappings from a provider's general cast-membership list. When the rendered markdown is only a player-loading screen, inspect the provider's directly retrieved HTML for visible credits and embedded character/name objects.

**Why:** iQIYI's browser extraction hid its detailed credit data while the original HTML exposed verified performer–character pairs. Broad searches mostly returned community databases, which could not satisfy the primary-credit requirement.

**How to apply:** Preserve a small dated source receipt, compare provider performer IDs across Chinese and international listings when available, and retain only premise-level character labels. Full provider credits can contain later-role aliases that must not be copied into a spoiler-light guide.
