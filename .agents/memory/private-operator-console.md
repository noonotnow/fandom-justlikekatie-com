The admin surface is an internal Operator Console, not a public Fandom Vibes destination. Keep it available for actor/Vibe Pack preflight, evidence review, verdicts, controlled publishing, and internal tests or changes.

**Why:** Daily Drop needs human-controlled checks for identity, image quality, and editorial eligibility, but public visitors should encounter the launchpad and fandom workbenches without operational controls.

**How to apply:** Preserve the private admin authentication boundary and noindex behavior while keeping public navigation free of admin links. Use the admin entry only for internal operations.
