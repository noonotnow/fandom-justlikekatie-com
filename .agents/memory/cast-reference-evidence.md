---
name: Cast-reference evidence
description: How to scope a character-to-performer guide when official pages supply incomplete credit evidence.
---

A distributor's actor list verifies participation, not a character-to-performer pairing. Require an explicit role attribution before adding a row to a primary-credit-based guide. Label secondary naming evidence separately; never imply a cast listing or synopsis check was an on-screen end-credit inspection.

**Why:** Official Untamed listings exposed actor participation more readily than role pairings. Secondary cast databases agreed on additional roles, but could not satisfy the requested primary-credit standard; a smaller verified reference was preferable to overstating evidence.

**How to apply:** When preparing future compact cast answers, record each source's exact evidentiary scope. Narrow the included rows if a primary role attribution is inaccessible, and disclose the omitted reader need rather than filling it from search snippets.

When a global distributor supplies only participation, check official localized drama sites and licensed broadcasters for explicit role headings. Separate the live-action actor from any localized `CV` (voice performer) credit.

**Why:** The Japanese official drama listing supplied an explicit role/actor heading where English distributor pages did not; its adjacent dubbing credit could otherwise be mistaken for the live-action performer.

**How to apply:** Record the original heading, access date, version context, and translation; extract names only rather than importing the localized character biography. Better evidence does not extend an existing creator approval.
