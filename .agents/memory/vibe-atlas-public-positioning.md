# Vibe Atlas public positioning

Treat Vibe Atlas messaging as funnel-wide: the SPA, launchpad, metadata, no-script fallback, C-drama learning pages, game pages, and generated result previews must all describe the curated daily card drop rather than a generic atmosphere tool.

**Why:** Updating only the main product surface left crawlable acquisition pages contradicting the public promise, and generated game previews inherited stale wording from their source template.

**How to apply:** When the Vibe Atlas promise or CTA changes, audit every public link into the product and regenerate derived pages from their source template before validation.
