---
name: Actor image feedback
description: Editorial boundary for image-level picks and rejections in private actor preflight reviews.
---

**Rule:** Image feedback is append-only and bound to the frozen audit run. Pin, hero, and supporting choices remain weak preferences for the next automated review. An Operator Rescue Board is different: it is a manual override that can use any nine retained, displayable images in the operator’s exact order, even when curation labeled them composite, unusable, duplicate, anti-anchor, or off-promise. Only missing/failed image URLs and explicit operator exclusions stay out. The override never rewrites the original audit, verdict, or Daily Drop eligibility. Exact source copies still share one image identity and resolve to the canonical retained representative.

**Why:** The algorithm must remain strict about what it recommends, but an operator should not have to defeat the same algorithm again to assemble a clearly better board from evidence already visible in the run.

**How to apply:** Require the blind Event/Compiled/Neither choice first when two boards are comparable; a comparison-unavailable run can still use rescue. Let the operator choose, reorder, and save exactly nine frozen images, preserving algorithm labels as evidence rather than vetoes. Treat changed-feedback arrangements as historical, and let prior picks break close automated-review ties only after current qualification passes.
