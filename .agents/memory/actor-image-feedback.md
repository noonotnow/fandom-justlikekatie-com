---
name: Actor image feedback
description: Editorial boundary for image-level picks and rejections in private actor preflight reviews.
---

**Rule:** Image feedback is append-only and bound to the frozen audit run. Pin, hero, and supporting choices remain weak preferences for the next automated review. An Operator Rescue Board is different: it is a manual override that can use any nine retained, displayable images in the operator’s exact order, even when curation labeled them composite, unusable, duplicate, anti-anchor, or off-promise. Only missing/failed image URLs and explicit operator exclusions stay out. Every save is a separate immutable, browsable receipt; opening one is read-only until the operator explicitly copies it into a new draft. An ordinary rescue save remains records-only; only an explicit calibration confirmation from a current-contract audit creates a separate immutable profile receipt whose bounded pairwise signals may influence future curation. Derive reusable query, source, cluster, and anti-anchor preferences from normalized selected-versus-omitted rates with minimum support and margin; a signal appearing on both sides is not automatically neutral. A fresh audit must show a same-evidence control-versus-calibrated improvement on candidates absent from the entire source audit, caused by a reusable query, source, or visual-cluster signal, before approval or Daily Drop eligibility can return. Candidate identity, hero placement, and anti-anchor effects can inform ranking or diagnostics but cannot prove transfer by themselves. Rescue calibration never rewrites the original audit, verdict, rescue, or eligibility decision receipt; current eligibility remains a derived projection. Exact source copies still share one image identity and resolve to the canonical retained representative.

**Why:** The algorithm must remain strict about what it recommends, but an operator should not have to defeat the same algorithm again to assemble a clearly better board from evidence already visible in the run. Explicit confirmation separates durable learning from ordinary audit history, while the full source-evidence exclusion and control comparison prevent memorized candidates, indirect reorderings, or mutable image retrieval from masquerading as transferable improvement. Binary set subtraction erased valid preferences whenever selected and omitted cards shared a publisher, query, or visual family; normalized rate deltas preserve meaningful editorial concentration while leaving weak overlaps neutral.

**How to apply:** Require the blind Event/Compiled/Neither choice first when two boards are comparable; a comparison-unavailable run can still use rescue. Let the operator choose, reorder, and save exactly nine frozen images, preserving algorithm labels as evidence rather than vetoes. Keep all receipts inspectable, export only records valid under the current run/feedback contract, and require an explicit “use as starting point” action before historical cards enter an editable draft. Treat changed-feedback arrangements as historical, and let prior picks break close automated-review ties only after current qualification passes. When calibration is confirmed, retain selected-vs-omitted rank, query, source, cluster, hero, and anti-anchor contrasts; consume them only within safety/promise gates, and invalidate proof if new receipts appear after the fresh audit.
