# 简体中文编辑声音指南（工作稿）

## 目标

写给看过仙侠、但不需要先参加术语考试的观众。声音要亲切、观察细、克制而有点冷面；幽默来自识别剧情为何非这样安排不可，不来自嘲笑观众、文化或角色。中文文案是重新写作，不按英文词序逐句翻译。

此稿适用于本次发布的核心浏览、收藏、九宫格、账户与会员说明，以及完整仙侠解码器。完整指南、术语表、小游戏、剧集与文章档案、追剧手记和讨论仍为英文；链接旁明确标注“英文”。第三方结账、邮件和系统分享面板不宣称已本地化。

## 仙侠解码器的笑点结构

1. **新人看到**：用一眼能懂的、对剧情安全的事件作开场。
2. **老观众知道**：点出恋爱、误会、身份揭晓或宇宙规则为什么非需要这个事件不可。不能只改名或预告接下来会发生什么。
3. **剧情机关**：用一句原创说明补上机制，读者即使不熟悉仙侠用语也能跟上。
4. 保持轻剧透：谈熟悉的叙事模式，不点具体剧名、集数、角色名或结局，不复述台词、剧本、梗概原文。

## 语气与中文节奏

- 优先用清楚、具体的普通话；句子短，动词靠前，标点符合简体中文习惯。
- 可以用“盖章、午饭、旧账、签收、进度条”等日常词，制造仙界制度与凡人生活的反差。
- “三界、仙君、渡劫、门派”等词用于对应的仙侠语境；不把现代网络流行语、英文 fandom 黑话或强行谐音当作笑点支柱。
- “老观众知道”应像一句克制的现场诊断。温柔地笑剧情机制，不把某类观众说成更聪明，也不把情绪和信任视为愚蠢。
- “仙君”用于特定仙侠语境而非所有男角色；“狐妖”是故事中的身份称谓，不作现实群体比喻。
- 让笑点落在叙事成本上：要制造误会，解释就得暂时停工；要让凡间日子变得重要，人物必须先拥有值得失去的生活。
- 会员说明必须区分三件事：所有已发布典藏卡组均可免费浏览、拼图和导出；发布不超过三天的单卡可免费保存；更早期单卡需核验收藏会员权限后保存。更丰富的演员氛围包与高级设计仍属会员权益。免费账户收藏同步不等于付费会员权益。

## 标点、双语与可访问性

- 页面 `lang` 使用 `zh-CN`。简体中文文案用中文全角标点；英文品牌名、剧种缩写和源标题按原样保留。
- 角色名、剧名、来源标题和其他外部元数据不做臆测式翻译；若跳转页面没有中文版本，链接上标注“（英文）”。
- 未核验语言的来源标题标注“来源原标题（未翻译）”，不要默认所有图片来源都是英文。已有中文编辑文案优先显示；确实只有英文的历史文案明确标注英文原文。
- 按钮、筛选器、搜索标签、空状态、分享结果和键盘焦点说明应使用相同的直白中文，不依靠颜色或笑话单独表达动作。
- 对屏幕阅读器保留明确标签、状态播报和 `aria-pressed`。语言切换仅携带白名单筛选类别和稳定公开卡片 ID；不携带输入的自由文本、账号、能力令牌或其他私有信息。
- 浏览器原生分享面板、剪贴板权限提示和第三方提供商界面由相应服务控制；本站只说明已验证的网页行为，不宣称这些界面已经本地化或在任何地区可用。

## 尚待母语审校

已完成一次追加的 AI 编辑复核，但不是母语审校认证。另一位审校者应特别检查：“伤情证明”的冷面幽默是否过重、“损失清单”是否保留温柔语气、“兼管晚饭和牵挂”是否自然，以及“天命的证人”“剧情替他改配色”是否一读就懂。“上一世的条款”“欠下的对视”保留了原文的荒诞比喻，仍值得比较更自然的中文写法。现有演员与氛围字段、分享片段也未因此获认证。自动化检查只验证功能，不代表语言自然度或发布批准。
