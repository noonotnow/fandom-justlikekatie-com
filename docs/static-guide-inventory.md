# Static C-drama guide inventory

`scripts/generate-public-pages.js` enforces the inventory during `prepare:public`
(also run by `predev` and `prebuild`), after generating journal pages and before
writing the sitemap. Releases therefore cannot skip it by skipping tests.
`scripts/public-pages.test.js` also compares filesystem `index.html` files under
`public/c-drama-fandom/` and `public/c-dramas/` with `shared/public-routes.js`.
Each file needs both its exact registered file path and its expected trailing-slash
route. Failures name the omitted file and route. This covers section indexes,
glossary, archetypes, watch journals, soundtrack, where-to-watch, drama guides,
and new nested sections without maintaining another section list.

The Vibing Now shelf index is included, but its articles remain the responsibility
of `scripts/vibing-public-inventory.js`. Neither the Vibing Now warning-copy
contract nor any source-review/publication gate is changed by this inventory.
Registration is not editorial approval.

## Exact exclusions

These generated LG01 result files are query-share previews, not independent
search-indexed editorial guides. Their public share URL is
`/c-drama-fandom/fandom-games/?fate=<slug>`; they are generated by
`scripts/generate-public-pages.js` and checked separately by the public-page tests.

There are currently **no shipped non-public fixture exclusions**. A future fixture
exception must name one normalized file path and a nonempty reason, recorded here
and in the inventory's fixture map. Test-only synthetic fixtures use temporary
directories and supply explicit file/reason maps. Directory wildcards, naming
conventions such as `drafts` or `previews`, and `noindex` metadata do not exempt
files. A new query-share preview must be explicitly reviewed and added to the
exact list; it does not inherit an exemption from its siblings.
