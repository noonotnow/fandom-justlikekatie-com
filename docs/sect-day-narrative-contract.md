# First Sect Day — authored V1

An independent English branching story, not LG02. No real characters or spoilers.
Five decisions always occur; choices are 0–2 in displayed order. Outcomes use
first-match precedence, never personality scores or random ties:

1. Carry the sword away → Wanted by Three Realms.
2. Any remaining final action with an unlimited arrival oath → Heavenly Vow.
3. Decline the sword, with visitor terms, copied map, or signed exit → Before Lunch.
4. Hold Wen responsible → Master's Favorite.
5. Close the circuit, having read the diagram and retained Ren or Sui → Sect Savior.
6. Otherwise → temporary containment.

Contrasting examples (zero-based choice sequences):

| Ending | Path | Another path |
| --- | --- | --- |
| Sect Savior | 1,0,0,1,0 | 2,0,1,2,0 |
| Three Realms | 0,0,0,0,1 | 2,2,2,2,1 |
| Heavenly Vow | 0,0,0,1,0 | 0,2,2,2,2 |
| Master's Favorite | 1,1,0,0,0 | 1,0,2,0,2 |
| Before Lunch | 2,2,2,2,2 | 1,1,0,2,2 |
| Back Mountain | 1,1,0,1,0 | 1,0,2,1,2 |

Arrival terms return at the stranger and crisis; the manual and treatment of
Ren return at the master; the master's answer returns at the crisis.
No path claims that leaving water is abandonment. Successful repairs identify
the actual witness. Containment guarantees Sui's inspection-hatch rescue.
The quiet exit is genuinely free of vows and penalties. Help and caution can
coexist; curiosity alone is neither a success condition nor a moral score.

Runs exist only in memory. Start and complete signals are distinct from shared
preview loads. Actions use fixed method IDs and only fire after browser success
(downloads mean a browser download was initiated, not proof the user saved it).
Export cards deliberately use generic ending text, never personalized causality.
