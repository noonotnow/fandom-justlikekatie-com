The two pinned principles are exactly the right guardrails:

## 1. CREATE is not the exit door

CREATE is the **publishing cockpit**, not the toll booth.

So the general-user loop stays clean:

> collect → build/remix grid → save → export/share
> 

And the creator/protected loop stays optional:

> grid → send to CREATE → copy variants → schedule/publish
> 

That means Vibe Atlas can stand as its own product instead of becoming a waiting room for CREATE OS.

## 2. Export is not the save button

Export = “make/share the artifact.”  

Save = “preserve the composition.”

That split is going to pay off *everywhere*:

- better UX
- cleaner data
- better collection semantics
- better recommendations
- less weird hidden state
- clearer future user permissions
- better “what did I actually like?” signal

Because a saved grid, exported grid, and CREATE-sent grid are three different levels of intent:

| Action | Meaning |
| --- | --- |
| Save | “I want to keep this composition” |
| Export | “This is output-worthy” |
| Send to CREATE | “This is content-pipeline-worthy” |

That is such good telemetry. The raccoon now has labeled jars.
