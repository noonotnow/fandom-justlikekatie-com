## Recommendation

For Middle-earth / MemeForge source search:

```
Google first
fallback only if needed
```

I’d use this priority:

1. **Google / Programmable Search**
    - Best default for recognizable LOTR scenes, characters, meme references, general web image/source grounding.
    - Better for Western fandom context and meme-language adjacency.
2. **Brave**
    - Good fallback if Google fails, rate-limits, or returns too little.
    - Useful for broader web discovery.
3. **Baidu**
    - Do **not** use as primary for LOTR/Middle-earth.
    - Keep it for C-drama / Chinese-platform workflows where it makes sense.

## Safety / quality note

This also matters because MemeForge should not let search results steer the joke too much. The engine should generate the meme concept from the **moment + fandom archetype**, then use search only to support the visual/reference layer.

So the flow should be:

```
Moment → meme translation → concept → optional source search
```

not:

```
Search result → weird source image → meme attempt
```

The latter is how we accidentally invent “Boromir holding a Taobao coupon,” which, while maybe art, is not the product.
