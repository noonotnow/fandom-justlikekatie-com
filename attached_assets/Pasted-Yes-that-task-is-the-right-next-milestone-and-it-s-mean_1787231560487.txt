I’d keep these as the non-negotiables:

- **Curated reaction-still families**
    - Boromir Council = impossible-task solemnity
    - Gandalf bridge = boundary / hard no
    - Gollum debate = internal conflict
    - Sam/Frodo = loyal support / shared burden
    - Frodo Mordor = dread / obligation
    - Hobbits eating = cozy treat logic

    - Use the new routing policy.

    - Typography-only should be a fallback, not the normal artifact.
- **Original copy only**

- **Rendering parity**
    - Preview, PNG export, saved/canonical render, packet persistence, and CREATE handoff all need the same visual contract.

## The product standard

The card should answer:

> “Would this still already land as a reaction before we even read the caption?”
> 

If yes, MemeForge is working.

If no, it’s still just a quote card with fantasy decor.
