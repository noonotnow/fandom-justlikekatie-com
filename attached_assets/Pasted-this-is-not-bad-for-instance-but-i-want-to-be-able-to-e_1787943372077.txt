Yes. That is the real advanced “Rework” path. It should not mean “place another caption somewhere around the existing meme.” It should mean:
Decompose the existing meme into an editable object, remove or replace its original text, and render a clean derivative.
The current implementation treats the source as one flat image and adds a Meme Forge overlay. What you want is closer to meme-aware Photoshop.
Correct three-path model
1. Use existing meme
Preserve the original raster exactly.
2. Rework existing meme
Import the meme, then:
Detect text regions with OCR.
Show each region as a selectable object.
Let the user keep, edit, or delete each text region.
Reconstruct the pixels behind deleted text using content-aware or generative fill.
Recreate retained/replacement copy as editable text layers.
Render the cleaned image and new layers into the exported derivative.
3. Forge from a still
Start with a clean franchise still and create an entirely new text composition.
That middle path should therefore produce an internal document resembling:
Original source
├── Cleaned background
├── Original-text region 1 [hidden/deleted]
├── Original-text region 2 [editable]
├── New text layer 1
├── New text layer 2
└── Export settings
​
Adobe’s role
An Adobe-backed pipeline makes sense because the difficult step is not OCR—it is plausibly rebuilding what was behind the text. The workflow would be approximately:
OCR/text detection → editable masks → Adobe content-aware/generative removal → layered composition → final render
The user should see detected text boxes directly on the image and be able to click:
Edit text
Remove text
Keep text
Adjust removal mask
Restore original
Then Meme Forge can suggest replacement copy, but the user remains in control of the actual visual surgery.
Important UX distinction
I would separate two levels inside Rework:
Quick overlay: Add text without altering the original pixels.
Deep rework: Detect and remove embedded text, then rebuild the meme as editable layers.
That prevents every rework from incurring an expensive Adobe operation while still making the serious capability available when required.
And yes: the generated artifact must be a rendered composite backed by an editable recipe, not merely a screenshot of the editor. Save:
Untouched original
Detected text and bounding boxes
Removal masks
Cleaned background
Replacement text layers and styling
Rendered derivative
Source/provenance relationship
So if someone chooses the Gandalf meme, they could export it untouched—or enter Deep Rework, select “IF YOU DON’T STUDY / YOU SHALL NOT PASS,” delete it, repair the image, and write a genuinely new joke in the original meme space.
That is advanced, but it is also the feature that makes Rework meaningfully different from “put a tasteful poster frame around a JPEG and hope nobody notices.”
